      Backup and restore

      Your posts, photos and videos live in Cloudflare storage. Download a backup now and then, and keep it somewhere safe (your computer, Google Drive). If anything is ever lost, restore from it here.

        Restoring only adds what is missing. It never deletes anything, so it is safe to run twice. A restore uses some of your free daily upload allowance (roughly 1,000 files a day).
